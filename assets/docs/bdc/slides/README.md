# Slide delle Lezioni — Sistemi Operativi

Carica qui i file delle slide, uno per lezione, seguendo esattamente questa convenzione di nome:

```
Lecture_<Parte>_<Numero>_<Titolo_In_Inglese>.pdf    → cartella pdf/
Lecture_<Parte>_<Numero>_<Titolo_In_Inglese>.html   → cartella html/
```

Esempio: la Lezione 1.1 (Parte I, prima lezione) corrisponde a:

```
pdf/Lecture_1_1_Fundamentals_of_Computer_Architecture.pdf
html/Lecture_1_1_Fundamentals_of_Computer_Architecture.html
```

Una volta caricato il file con il nome corretto, il pulsante corrispondente in `teaching/os.html`
funzionerà automaticamente — non è necessario modificare alcun codice.

Consulta `teaching/os.html` (sezione `#lezioni`) per l'elenco completo dei nomi file attesi,
lezione per lezione.
